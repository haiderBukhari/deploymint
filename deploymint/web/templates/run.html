Pipeline
  • 1
    Architect
    Scans the repo with tree-sitter, builds the import graph, ranks files by PageRank criticality.
  • 2
    Artifact Smith
    Generates the Dockerfile and Kubernetes manifests, tailored to this repo — Claude-backed with a deterministic template fallback.
  • 3
    Security Warden
    Scans everything generated with Checkov and custom OPA policies. This is the gate — a failing scan blocks the deploy.
  • 4
    Red Team
    Adversarially probes for backdoors, prompt-injection compliance, and supply-chain risks the scanners above wouldn't catch.
  • 5
    Execution
    Builds the image via the mounted Docker socket and deploys it — to your cluster if one's reachable, otherwise a plain docker run.
  • 6
    Oracle
    Watches the fresh deploy for a short window and rolls it back automatically on a crash loop or repeated restarts.
  • 7
    FinOps
    Estimates monthly cost from the generated manifest's resource requests — deterministic arithmetic, never an LLM guess.

Fills in live over the WebSocket connection below; on a finished run it replays instantly from the persisted event log.
